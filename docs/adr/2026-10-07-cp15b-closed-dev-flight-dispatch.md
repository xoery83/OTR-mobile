# CP15B — CLOSED DEV Flight dispatch foundation

Date: 2026-10-07. Status: implemented in the Owner-authorized Builder worktree;
activation remains CLOSED and independent implementation review is pending.

## Decision

Server84 adds one versioned DEV/FLIGHT_IMPORT_V1/DeepSeek activation aggregate,
Security Admin Account grants and immutable call resource holds. The existing
verified gateway, request journal, scope locks, call/START records and usage/cost
observations retain authority. Only a dedicated SECURITY_ADMIN runtime root can
change DEV runtime. TEST and PRODUCTION remain structurally false. CONFIG_ADMIN
proposes configurations; Security Admin explicitly selects each exact version.
Migration installation creates no active scope, grant, price or credential.

Missing approved provider-currency monetary policy denies admission. Conservative
integer nanos holds and UTC admission-day counters never refund automatically.
Unknown execution retains its hold and never authorizes redispatch. Default retry
limit is one; any explicitly selected higher bound still requires a linked prior
same-provider terminal FAILED call and durable completion, plus C2 responsibility
closure and fresh admission. There is no automatic repair prompt or fallback.

The existing SQLite50 descriptor JSON carries a truthful remote v2 descriptor;
request/result private custody and the existing publication tuple associate the
Run with attempt, original evidence, configuration, execution and usage. No SQLite51
or second scheduler is needed. Local v1 contracts remain local. Remote v2 rebinding
enters the same CP13B validation/matching/proposal core; CP13A keeps canonical
Event authority and every five-C operation denial remains unchanged.

A Backend-private injected resolver accepts only authenticated DEV/DeepSeek host
context and the fixed logical reference. No real resolver, key read, live transport
factory or HTTP endpoint is installed. The adapter accepts only a network-disabled
fixture transport, a fixed destination and a durable mark ACK. Selected text spans
are untrusted data. Only opaque tokens and semantic hints return; the host recovers
original UTF-8 spans and normalizes them deterministically. Unsupported private
dimensions remain local deferred evidence. Raw attachments never go to the provider.

## Consequences

CP15B is reviewable CLOSED implementation, not authorization for CP15B-LIVE.
A later live checkpoint must separately approve monetary ceilings, credential
provisioning, host/custody deployment and real transport. No secret, Hosted
Dev/Production, real provider call, Vision, Apple, public B2, shadow or fallback
activation is part of this work. Existing accepted CP13/CP14 documents are preserved.
