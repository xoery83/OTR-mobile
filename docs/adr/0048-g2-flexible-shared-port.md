# ADR 0048: G2 Flexible shared presentation port

Status: Accepted for synthetic Lab extension only (G2-FLEX-01, Owner Review pending).

Use a versioned Block projection and a shared Focus/Immersive host in the existing Day Feed Composer. Keep existing Canonical Item renderers, NOW placement and TTR candidate logic. Block rows are independent, with explicit unique Item affiliation and outer fallback. CP01A's isolated Gallery projection is adapted only after CP01B authorization; G2 does not import its feature code or own Flexible lifecycle.
