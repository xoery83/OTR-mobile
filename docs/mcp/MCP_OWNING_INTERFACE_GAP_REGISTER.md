not new policy. Archive/delete/settlement/invitation/account linking are outside
this authorization; they were not added as implied future capabilities.

command/request-digest binding with either receipt or first-send reservation.

foreign binding remains UNKNOWN and never causes a new POST. A host must not
echo a new caller digest over a previously stored receipt.

requiredScopes only filter actual signed business grants. Provider read-only policy
omits domain writes. No OIDC claim alone grants an OTR domain permission.
