# Using OTR with an AI platform

Connection support is being prepared. OTR has verified ChatGPT Trip-list reading
in limited testing; a public OTR installation is not yet available. Claude has
passed limited Trip and complete Item reads; consumer editing remains
under validation. Opening a platform does not install
OTR, sign you in or authorize access.

## In OTR

Use Settings → Connected AI when the Native entry has shipped. Today this route
is a delivery target, not an installed-app claim. Choose a platform to read its
current capability and connection instructions. Existing authorizations are
managed in that platform; OTR does not yet display a server-verified connection
status. You never need a second OTR app for another AI platform.

## ChatGPT

Open [ChatGPT](https://chatgpt.com/). Once a public OTR entry is available, use that
verified entry and complete the normal OTR browser login and explicit permission
review. Return to ChatGPT, select OTR and ask it to read data you can access.
Current [official custom-server instructions](https://developers.openai.com/api/docs/guides/custom-mcp-server)
use Plugins; availability and controls depend on the actual account. OTR currently
has no approved public install link. Do not use an unofficial URL or assume a
prefilled message installs a plugin.

Current read example: “Use OTR to list Trips I can access. Do not change any data.”

## Claude

Open [Claude](https://claude.ai/). Its [official remote-connector guide](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)
describes Customize → Connectors. If a direct OTR entry is not available, follow
OTR's published instructions when they become available; no public server address
is supplied here. A visible custom-connector form does not prove OTR is connected.

Gemini and other platforms are future compatibility work. No install is implied.

## Permission and saving

Review the Account and requested permissions during OTR authorization. Opening a
link grants nothing. OTR should report an operation's actual result, including
pending, conflict or unknown; a request being sent is not evidence it was saved.
Consumer saving/editing instructions will be enabled after verification. The
future planning example is: “Read my Nelson Trip in OTR, prepare the next few days,
and show a preview before saving.” It is not a current Write capability claim.

If access stops, review the connection in your AI platform. Do not reuse a cached
answer as a fresh read or share passwords/tokens in a prompt. Disconnect the OTR connection in that platform when you no longer want to use it.
Existing read results may remain in that conversation.
