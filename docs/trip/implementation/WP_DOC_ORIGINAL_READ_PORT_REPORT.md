# WP-DOC-ORIGINAL — dormant Backend read port

This isolated R0/R1 packet adds a read-only Backend composition port for an original operational Document. It does not mount `GET /trips/:id/documents/:documentId/download`, enable `canReadOriginal` in the default Core PG connection, sign a URL, change storage permissions, or expose a viewer. No real original or protected DEV business object was read.

The caller supplies the authenticated actor Account separately from the request's actor/Trip/Document ID, content version and expected SHA-256; a mismatch is denied before any provider call. The injected current Core reader must return the live actor, graph and monotonic Trip access revision. The port applies Core's existing `coreCanRead(..., "DOCUMENT", ...)` ACL, rejects hidden or mismatched rows, and allows only the current immutable version/hash. An independently injected owning custody reader first proves BOUND retention plus current Source right for `PRIVATE_SOURCE_REFERENCE` or current explicit copy grant for `AUTHORIZED_COPY`; only then may its byte reader resolve a private locator internally and supply at most 10 MiB binary or 1 MiB text. The port verifies exact size/hash, then rechecks custody generation and Core ACL/access/document revision before returning a copied byte array. Any absent authority, failed check, changed revision/generation, invalid request or provider error returns only `UNAVAILABLE`; no locator or provider detail is returned. A consumer must not persist the returned bytes without its separate account-gated verified cache contract.

The injected adapters are **not implemented or wired** by this packet. A production adapter must obtain Core facts from the current owning read/actor context and custody facts from the actual retained-object provider; it may not turn an Item link, Source registration receipt, visibility alone, or a caller-supplied flag into original rights. The current default `createCorePgHttpConnection` therefore remains fail closed. The existing Ledger receipt `Sharing.shareAsync` path is domain-specific and proves no common Document viewer or offline-original capability. Source PDF registration verifies producer bytes, not end-user access.

Focused tests use synthetic Core and custody facts for authorized copy and Source-reference denial, stale version/hash, denied actor, absent ports, changed bytes/size, revoked rights, changed Core revision and custody generation, provider failure, and no storage-key leak. These tests establish the port's conditional logic only. Actual Core/custody adapter composition, HTTP response, Mobile repository/cache/OS opener, real ACL/custody bytes and Native acceptance remain separate work with their own gates. No runtime authorization or Beta-ready claim follows.
