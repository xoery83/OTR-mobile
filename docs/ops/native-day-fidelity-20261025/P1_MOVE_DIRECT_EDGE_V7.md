- The line follows the actual finger Y within system safe bounds. It never snaps to a gap or shifts existing card heights. In the viewport interior the feed stays still; dragging within the top/bottom56pt zones starts continuous edge scrolling, deeper means faster. Leaving an edge immediately clears velocity. In a timed Day, primary/secondary clock text is measured through optional readonly P1Row wrappers, and only that Day's visible clock anchors constrain the time. Cross-day END clock text is never treated as an in-day clock for the preceding Day. Exact displayed clocks are honored even in coarse mode; rounding cannot escape the neighboring visible clock bounds or change the date.

The usable gesture area expands to the system safe insets. Release/cancel/interruption restores them. Explicit empty native title prevents route-name fallback.
