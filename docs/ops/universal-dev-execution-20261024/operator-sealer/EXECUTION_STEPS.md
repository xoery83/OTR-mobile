This local Operator is a pure proposal builder, not a Source reader, identity issuer or admission receipt. No network/SQL/Auth/Provider call, secret loading or AppDB access. All original Source IDs/operations come from the fixed actual Native receipt; only explicit new Operator identities are proposed. Templates containing null cannot execute.
