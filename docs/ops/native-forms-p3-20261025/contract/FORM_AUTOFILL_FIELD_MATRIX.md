# P2–P6 Form-scoped field coverage — Matrix B

**Scope:** 2026-10-23 read-only compatibility. Field vocabulary is from [Part 1 Product Delta, “P2 Flight Create / Journey grouping / P2 Edit”](../../beta/form-booking-part1-v1-20261018/PRODUCT_DELTA.md), [Part 1 Core Supplement GAP-02/03](../../beta/form-part1-core-delta-v1-20261018/FORM_PART1_CORE_DEPENDENCY_SUPPLEMENT.md), [Part 2 Product Delta P3–P6](../../beta/form-booking-part2-final-v1-20261018/PRODUCT_DELTA.md), [W0 field matrix](../../trip/contracts/W0_FIELD_AUTHORITY_MATRIX.csv) and [TICKET-IDENTITY-01](../../beta/form-booking-part2-final-v1-20261018/TICKET_IDENTITY_01.md). `W` below is frozen `49c9516e...` `llm-first.ts:allowedPaths`, `real-llm-compact.ts:compactSchema`, `real-llm-evidence.ts:inspectCompactEvidence`. A permitted `W` path carries raw value and text-span/image-region Evidence, **not** canonical proof, verified place/Person, or a working Form adapter.

Status is **output-schema coverage only**: `SUPPORTED` = W has an exact observed path and typed/locator validation; `MAPPABLE` = observed path exists but Form/Core normalization, identity or endpoint/temporal mapping remains; `MISSING` = no current W Item field path and evidenced optional Source Observation must be added; `DEFERRED` = relationship/authority, not a scalar Form patch. For every row, Create writes only empty/untouched Draft fields; Edit binds current authorized Item ID + revision, respects Dirty/Clear, offers per-field Keep/Replace on conflict. The same Batch may produce **N independent same-family Drafts**, with temporary tokens retained separately; no automatic Save or Universal Batch Review. Existing W arrays/tokens permit N objects, but the Form-scoped Draft adapter and multi-save orchestration are not implemented. This common rule applies to every row and is a delivery gap, not a claim that Form Autofill runs today.

## Exact Form field/type inventory for the grouped mapping rows

The mapped row above applies separately to each comma-separated field below. `Date` is a civil YYYY-MM-DD, `Clock` a local clock plus precision, `Zone` an explicit IANA zone observation, `Place` authored text or a separately qualified accepted Place, `PersonRef` an authorized same-Trip Person ID, `SourceRef` an owning Source/Representation identity, and `ItemRef` an existing authorized Item ID/revision. These are *business types*, not claims that the current W raw string is already normalized to them. F1/F1C/F2 define Form presence; C §3 and M named rows control canonical types.
