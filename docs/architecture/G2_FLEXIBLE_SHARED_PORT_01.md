# G2 Flexible Shared Port / 1

G2 accepts only authorized synthetic `g2-flexible/1` Block projections in the Day Feed Lab. A Block has its own date, title, soft window, explicit Item IDs, and scoped Choices. It is a presentation row, never a Canonical Item or a source of TTR adjacency. CP01A's `FlexibleFixtureProjection` (`flexible-fixture/1`) remains isolated; CP01B must adapt its Block/Resource/affiliation facts to this port after authorization. No CP01B implementation or production Flexible read contract exists on canonical main.

The Composer owns one placement per visible Item: only a unique, same-day TIMELINE affiliation can nest. Missing, ambiguous, BASE or TNS Items remain outer rows. Soft windows position Blocks by start when available, without clipping Items or inferring hard time. A Block can render with no Items or Choices. The header opens Block Immersive directly and never becomes Focus. One Focus key addresses either a Canonical Item ID or a Choice key (`["FLEXIBLE_CHOICE", blockId, scope, choiceId]`); the G2 host owns this state. My/Group filters only Choices, defaults to My when populated and otherwise Group. NOW and TTR remain based on Canonical Item rows.

The old DL4 `FlexibleContainer` metadata seam stays compatible for existing callers. `g2-flexible/1` is a bounded Lab presentation contract, not Flexible business storage or authorization. The Lab contribution must be synthetic and trip-scoped. CP01B must supply authorized, scoped projections; G2 will not accept arbitrary Gallery state, lifecycle commands, providers, or Core writes.
