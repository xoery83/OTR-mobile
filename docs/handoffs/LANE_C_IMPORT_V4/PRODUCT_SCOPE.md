## Product rules that remain binding

- Precision-first: preserve unknown times/places/people; address text is not a
  confirmed Place, Guest Name is not a Trip Person, samePNR is not a Journey.
- Photo preprocessing is Local OCR relevance→actual original-image Vision→existing
  results/review/save. IRRELEVANT retains original/no paid call; UNCERTAIN waits for
  explicit Continue/Skip; poor OCR alone cannot prove irrelevance.
- Native Capture/Form originals are Local Durable first. Backend processing copies
  are not permanent backup. Sharing requires real upload/accessibility/ACL.
- Normal Account/Actor/Trip, receipt/revision/UNKNOWN and budget rules remain.
  No second Parser, canonical Save, Source/Task/permission or notification platform.
