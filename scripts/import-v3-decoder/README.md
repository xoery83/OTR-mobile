# Import V3 Backend decoder package

The existing Backend container has no Docker client. This build layers the
previously qualified image codec, QPDF/Poppler tools, fixed decoder scripts
and the nonprivileged launcher into the exact Backend base. The codec images
in the Dockerfile supply build assets. The V3 runtime launches a short local
child process. The legacy PDF/PNG transport and its own artifacts remain
separate.

Build from a temporary context containing the files below. Supply the exact
reviewed Backend image ID as `BACKEND_BASE`. The image's existing Backend user
owns the normal server bundle. The decoder files are root-owned.

- This directory's `Dockerfile`, `sandbox.c`, `probe.mjs` and `decode-pdf.mjs`
- `extract.mjs` and `profile.mjs` from `scripts/source-pdf-v2-linux`
- The `dist/server-capture.mjs` generated by `npm run backend:build:capture`

The launcher requires Landlock ABI 3 or newer, installs its filesystem rules
and seccomp under no-new-privileges, then starts a resource-limited process
with a fixed environment. The runtime readiness probe checks both image and
PDF dependencies inside that sandbox. Runtime configuration adds no socket,
credentials, Linux capabilities or network mounts. The existing health phase
can run the probe as the existing Backend user. Preserve a closed outcome if
the inherited runtime policy rejects it. [Linux Landlock documentation](https://docs.kernel.org/userspace-api/landlock.html) · [Linux seccomp documentation](https://docs.kernel.org/userspace-api/seccomp_filter.html)

For local synthetic verification, bundle `acceptance.ts` with esbuild
(`--bundle --platform=node --target=node24 --format=esm`) and pass the
bundle to `node --input-type=module` via standard input. Use a disposable
read-only, network-none container with the candidate image and a private
16 MiB `/tmp` tmpfs. Supply the checked-in
`backend/src/__fixtures__/source-pdf/synthetic-roundtrip.pdf` as base64 in
`OTR_V3_SYNTHETIC_PDF`. The harness verifies local isolation, four image
formats, negative inputs, two PDF pages and scratch cleanup. The fixture
does not use a shared service.
